# ResumeIQ - AI Resume Screening System

An AI-powered Resume Screening and ATS Scoring System built using Python, Machine Learning, NLP, Flask, and SQL.

## Features

- Resume Classification
- ATS Score Generation
- Resume Parsing
- Candidate Ranking
- Skill Gap Analysis
- Recruiter Dashboard

## Tech Stack

- Python
- Scikit-learn
- NLP
- Flask
- SQLite / MySQL
- HTML, CSS
- Git & GitHub
